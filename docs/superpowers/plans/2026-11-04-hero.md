# Pitali Hero Implementation Plan

Goal: construir a primeira etapa aprovada da loja Pitali, mobile first.

Architecture: Astro renderiza estrutura; React controla hero com GSAP e ScrollTrigger. CSS Tailwind e estilos de componente. Um único controlador de scroll, sem Lenis. Movimento por transform e opacity; acessibilidade reduced-motion.

Spec: PROJECT_CONTEXT.md e instrução explícita do usuário nesta conversa.

## Tasks
- [x] Criar base Astro React Tailwind, scripts dev/build/check e copiar ativos originais.
- [x] Implementar header Pitali, hero com texto Vista seu movimento e CTA Explorar fitwear. Sem funcionalidades falsas de busca, sacola ou checkout.
- [x] Scroll: texto sai, foto amplia para viewport, deslocamento vertical sutil, gradiente off-white inferior libera próxima seção. Preservar enquadramento no mobile; nenhuma distorção da fotografia.
- [x] Próxima seção mínima para testar transição, sem inventar produtos/preços. Catálogo e rail ficam para próximas etapas.
- [ ] Validar build, check e viewport mobile/desktop quando navegador estiver disponível. Garantir reduced-motion, fallback sem JS e ausência de overflow horizontal.

## Review focus
Altura variável do navegador móvel; recorte dos rostos; navegação por teclado; redução de movimento; reversão do scroll sem saltos. Não há camadas separadas na foto original: nesta etapa usar parallax da foto inteira e registrar limitação.
